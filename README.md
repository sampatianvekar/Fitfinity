# 🏥 Fitfinity — Health & Wellness Platform

> A full-stack health and wellness web application built with PHP, MySQL, and Bootstrap. Fitfinity helps users find trusted doctors, book appointments, and access curated content on diet, fitness, parenting, and ASMR.

## 🌟 Features

- 👨‍⚕️ **Doctor Finder** — Search specialists by category (Kids / Adults) and speciality
- 📅 **Appointment Booking** — Easy online appointment scheduling with doctor, date & time selection
- 🔐 **Secure Login / Signup** — PHP session-based authentication with password hashing
- 🥗 **Diet Plans** — Curated affordable Indian diet plans
- 💪 **Fitness Section** — Exercise routines for all fitness levels
- 👨‍👩‍👧 **Parenting Tips** — Mindful parenting advice and resources
- 🎧 **ASMR Therapy** — Relaxation content for stress relief and better sleep
- 🌐 **Google Translate** — Multilingual support for linguistic diversity
- 📱 **Responsive Design** — Mobile-friendly across all screen sizes

## 🚀 Getting Started

### Prerequisites
- [XAMPP](https://www.apachefriends.org/) installed (PHP + MySQL)
- Git

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/sampatianvekar/Fitfinity.git

# 2. Move to XAMPP htdocs folder
# Copy the project to: C:/xampp/htdocs/

# 3. Import the database
# Open phpMyAdmin → Create a new database → Import the .sql file

# 4. Start Apache and MySQL in XAMPP

# 5. Open in browser
http://localhost/Fitfinity/php-signup-login-main/home1.php
```
